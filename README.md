# Start8Charms
Windows 8 Start Menu with Charmas Bar for Windows 10

Run build.bat, it will create CharmsBar.exe
Run CharmsBar.exe

It will differenciate Start Menu using Windows Key and using CharmsBar 

**No live tiles**
